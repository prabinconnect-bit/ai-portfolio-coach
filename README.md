# AI Portfolio Coach public pages

This folder contains a draft static website for GitHub Pages. It is separate from the existing AI Portfolio Coach plugin; it does not modify the plugin source.

## Before publishing

1. Review `privacy.html` and `terms.html` for accuracy. These are draft templates, not legal advice.
2. Replace the placeholders in `support.html` with your actual public repository and Issues URLs.
3. Set the effective dates in the privacy policy and terms to the date you publish them.
4. Review the homepage, publisher name, and template link.
5. Keep GitHub Issues free of secrets and sensitive personal information.

## Publish with GitHub Pages

1. Create a **new public repository** named `ai-portfolio-coach-pages` (or another name you choose). Do not use the existing plugin repository if it contains private material.
2. Upload all files from this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to deploy. Copy the actual published URL from Settings → Pages.
6. Open the homepage, Support, Privacy, and Terms links in a private/incognito browser window to confirm they are publicly accessible.
7. Update `support.html` with the real repository and Issues URLs and commit the change. If you edit that file after first deployment, wait for redeployment and verify again.

## Important

Do not enter guessed URLs into the plugin listing. Use only URLs that were actually published and checked.
